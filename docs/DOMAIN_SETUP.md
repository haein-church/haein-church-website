# 도메인 설정 (DOMAIN_SETUP)

- 갱신일: 2026-11-09
- 상태: **사용자 승인 대기**. 신규 도메인 미정.

## 확인 필요 항목 (사용자)

1. 사용할 도메인 이름과 소유 여부
2. 도메인 등록업체와 DNS 관리 권한
3. Cloudflare DNS 사용 가능 여부
4. 기존 이메일 서비스의 MX, SPF, DKIM, DMARC 레코드

## 원칙

- 도메인을 임의로 구매하거나 결제하지 않는다.
- DNS 변경 전 현재 설정을 백업한다.
- 기존 이메일이나 다른 서비스에 영향을 주는 레코드는 삭제하지 않는다.
- 리다이렉트 가능 여부는 도메인 확정 후 확인한다.
